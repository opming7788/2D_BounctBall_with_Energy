# 2D 彈跳球能量守恆模擬

👉 [點我進入觀看模擬](https://opming7788.github.io/2D_BounctBall_with_Energy/2D_BounctBall_with_Energy.html)
此專案是一個基於 HTML5 Canvas 的 2D 彈跳球模擬，展示了能量守恆的概念。以下是技術細節：

## 使用技術

1. **HTML5 Canvas**:

   - 使用 `<canvas>` 元素進行 2D 圖形繪製。
   - 提供動態繪製球體、文字及其他圖形的能力。

2. **JavaScript**:

   - **物件導向設計**:
     - `CanvasHelper` 類：負責管理畫布上的物件，提供繪製、移動、刪除等功能。
     - `Ball2` 類：模擬球體的物理屬性（位置、速度、質量）及其行為（碰撞、反彈）。
   - **物理模擬**:
     - 球體與牆壁的碰撞檢測與反彈 (`ReboundWithWall`)。
     - 球體之間的碰撞檢測與速度更新 (`Collision_of_Balls`)。
     - 能量計算函數 (`CalEnergy`) 用於計算系統的總動能。
   - **動畫處理**:
     - 使用 `requestAnimationFrame` 實現平滑的遊戲主循環。
     - 動態更新畫布內容，展示球體運動及能量變化。

3. **CSS**:
   - 設計簡潔的畫布樣式，提供視覺化的模擬環境。

## 功能

- 模擬兩個球體在封閉空間內的運動。
- 支援球體與牆壁、球體與球體之間的碰撞。
- 動態顯示球體的速度、質量及系統總能量。
- 能量守恆的即時計算與展示。

## 如何運行

1. 打開 2D_BounctBall_with_Energy.html 文件於瀏覽器中。
2. 觀察球體的運動及能量變化。

## 應用場景

- 教育用途：展示能量守恆與碰撞的物理概念。
- 互動模擬：提供簡單的 2D 物理引擎範例。
